# Smart Expense Tracker API

A lightweight REST API to track and summarize personal expenses built using Node.js and Express.

## Features
- Add new expenses with automated ID generation
- View all expenses or filter by category
- Calculate total expenditure and breakdown by category
- Delete expenses by ID
